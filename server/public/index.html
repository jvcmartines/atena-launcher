Versão do jogo

Para o Atena: Minecraft 1.20.1 com loader forge. Em "versão do loader" você pode usar latest, recommended ou fixar uma build (ex.: 1.20.1-47.3.0) — fixar é mais seguro, porque garante que todo mundo roda exatamente o mesmo Forge.

Servidor mostrado no launcher

O IP aparece na tela inicial do launcher com um botão de copiar, e é usado para mostrar se o servidor está no ar e quantas pessoas estão jogando.

Sincronização dos arquivos

São as coisas do jogador que o modo estrito não pode apagar: mundos, prints, teclas configuradas, waypoints. Dica: se você quer que os jogadores possam mexer nos configs sem serem sobrescritos a cada atualização, adicione config nesta lista — em troca, ajustes de config que você fizer param de chegar até eles.

Backup antes de atualizar

Antes de sincronizar o modpack, o launcher copia estas pastas para backups/ na máquina do jogador. Ele guarda as 5 cópias mais recentes e apaga as antigas sozinho.

Serve de rede de segurança: se você esquecer de colocar uma pasta na lista de ignorados acima, o conteúdo do jogador ainda pode ser recuperado. Não precisa repetir aqui o que já está ignorado — aquilo nunca é apagado.

Quem pode ver este modpack

Este filtro roda no servidor: um modpack que a pessoa não pode ver simplesmente não aparece para ela, nem os arquivos ficam acessíveis. É assim que se faz uma versão de testes só para a staff.

Para pegar o ID de um cargo: no Discord, ative o Modo Desenvolvedor (Configurações → Avançado), clique com o botão direito no cargo e escolha "Copiar ID do cargo".

Aceita o nome de usuário do Discord ou o ID. Dá para copiar direto da aba Jogadores.

Atenção: qualquer opção diferente de "todo mundo" exige que a verificação por Discord esteja ligada em Launcher → Verificação por Discord.

Whitelist por nick (opcional)

Filtro simples pelo nick do Minecraft, feito dentro do launcher. Serve para organizar, não para proteger — quem souber mexer contorna. Para valer de verdade, use o controle de acesso acima.

Manutenção

Login dos jogadores

Sem preencher nada o login já funciona, usando o client_id público que vem na minecraft-java-core. Registrar o seu próprio app no Azure só é necessário se quiser a tela de login com a sua marca. Lembre que login Microsoft exige online-mode=true no servidor.

Verificação por Discord

Com isso ligado, o jogador conecta a conta do Discord dentro do launcher. Aí você consegue liberar modpacks por cargo, banir alguém do launcher, e ver qual nick de Minecraft pertence a qual pessoa do Discord.

Quem tiver esse cargo aparece com um selo (Staff) ao lado do nick, dentro do launcher. Quem decide isso é o servidor, então trocar o cargo aqui basta — ninguém precisa atualizar o launcher.
